# Plan del proyecto de ejemplo

## Objetivo

Lanzar una primera versión para un grupo reducido de usuarios y medir el uso antes de ampliar.

## Fases

| Fase | Duración | Resultado |
| --- | --- | --- |
| 1. Descubrimiento | 2 semanas | Problemas validados |
| 2. Prototipo | 4 semanas | Versión navegable |
| 3. Piloto | 6 semanas | Primeros usuarios reales |

## Riesgos

- Que el equipo no alcance a cubrir el soporte durante el piloto.
- Que los datos de ejemplo no representen casos reales.
- Que el diagrama de flujo cambie: ver [diagramas](../guia/diagramas.md).

## Próximos pasos

1. Definir quiénes participan del piloto.
2. Preparar datos de prueba **sintéticos**.
3. Fijar una fecha de revisión.
